# Glossary

Short definitions of terms that come up on SY0-701. Most acronyms here appear in CompTIA's official objectives and acronym list. Each links back to the domain where it matters most.

| Term | Meaning |
|---|---|
| AAA | Authentication, authorization and accounting: proving identity, granting rights, recording activity ([Domain 1](domains/1-general-security-concepts.md)) |
| ABAC | Attribute-based access control: decisions from attributes of user, resource and context ([Domain 4](domains/4-security-operations.md)) |
| ACL | Access control list: rules that allow or deny traffic or actions |
| AES | Advanced Encryption Standard, the common symmetric cipher |
| ALE | Annualized loss expectancy: SLE x ARO ([Domain 5](domains/5-security-program-management-and-oversight.md)) |
| APT | Advanced persistent threat: a skilled, patient attacker, often a nation-state |
| ARO | Annualized rate of occurrence: expected events per year |
| AUP | Acceptable use policy: what users may and may not do with company systems |
| BIA | Business impact analysis: what an outage costs and how fast systems must return |
| BPA | Business partners agreement: terms between business partners |
| BYOD | Bring your own device: employees use personal devices for work |
| CA | Certificate authority: issues and signs digital certificates |
| CIA | Confidentiality, integrity, availability |
| COPE | Corporate-owned, personally enabled device |
| CRL | Certificate revocation list |
| CSR | Certificate signing request: a public key and identity details sent to a CA |
| CVE | Common Vulnerabilities and Exposures: IDs for known vulnerabilities |
| CVSS | Common Vulnerability Scoring System: severity score from 0.0 to 10.0 |
| CYOD | Choose your own device: employee picks from approved company devices |
| DDoS | Distributed denial of service: many sources flood a target |
| DKIM | DomainKeys Identified Mail: signs outgoing email |
| DLP | Data loss prevention: detects and blocks sensitive data leaving |
| DMARC | Policy telling receivers what to do with mail that fails SPF or DKIM, and where to send reports |
| DMZ | Demilitarized zone, also called a screened subnet, for public-facing servers |
| EAP | Extensible Authentication Protocol: framework used by 802.1X |
| ECC | Elliptic curve cryptography: asymmetric crypto with short keys |
| EDR | Endpoint detection and response |
| EF | Exposure factor: share of an asset lost in one event |
| FIM | File integrity monitoring |
| HIPS | Host-based intrusion prevention system |
| HSM | Hardware security module: tamper-resistant device that protects keys for many systems |
| IaaS | Infrastructure as a service: you run the OS and up, the provider runs the hardware and hypervisor |
| IaC | Infrastructure as code |
| ICS | Industrial control system |
| IDS | Intrusion detection system: detects and alerts |
| IPS | Intrusion prevention system: detects and blocks, inline |
| IPsec | Network-layer encryption, common for site-to-site VPNs |
| JIT | Just-in-time permissions: temporary elevated access |
| LDAP | Lightweight Directory Access Protocol |
| MDM | Mobile device management |
| MFA | Multifactor authentication: two or more different factor types |
| MOA | Memorandum of agreement: cooperation with defined responsibilities |
| MOU | Memorandum of understanding: shared intent, usually not binding |
| MSA | Master service agreement: overall terms for an ongoing relationship |
| MSP | Managed service provider |
| MTBF | Mean time between failures |
| MTTR | Mean time to repair |
| NAC | Network access control: checks devices before letting them on |
| NDA | Non-disclosure agreement |
| NGFW | Next-generation firewall |
| OAuth | Authorization framework for delegated access with tokens |
| OCSP | Online Certificate Status Protocol: real-time certificate validity check |
| OSINT | Open-source intelligence |
| PaaS | Platform as a service |
| PAM | Privileged access management |
| PKI | Public key infrastructure |
| RADIUS | AAA protocol for network access such as VPN and Wi-Fi |
| RBAC | Role-based access control |
| RPO | Recovery point objective: maximum acceptable data loss, in time |
| RTO | Recovery time objective: maximum acceptable downtime |
| RTOS | Real-time operating system |
| SaaS | Software as a service |
| SAE | Simultaneous Authentication of Equals, the WPA3-Personal handshake |
| SAML | Security Assertion Markup Language: XML assertions for federated SSO |
| SASE | Secure access service edge: cloud-delivered networking and security |
| SCADA | Supervisory control and data acquisition |
| SCAP | Security Content Automation Protocol |
| SD-WAN | Software-defined wide area network |
| SDN | Software-defined networking |
| SIEM | Security information and event management |
| SLA | Service-level agreement |
| SLE | Single loss expectancy: asset value x EF |
| SOAR | Security orchestration, automation and response |
| SOW | Statement of work |
| SPF | Sender Policy Framework: DNS list of servers allowed to send a domain's mail |
| SSO | Single sign-on |
| TLS | Transport Layer Security |
| TOC/TOU | Time-of-check to time-of-use race condition |
| TPM | Trusted Platform Module: key-storage chip in one device |
| UTM | Unified threat management: several security functions in one appliance |
| VPN | Virtual private network |
| WAF | Web application firewall |
| WPA3 | Wi-Fi Protected Access 3 |
| XDR | Extended detection and response |
| XSS | Cross-site scripting |
| Zero Trust | Security model with no implicit trust based on network location ([Domain 1](domains/1-general-security-concepts.md#12-fundamental-concepts)) |
